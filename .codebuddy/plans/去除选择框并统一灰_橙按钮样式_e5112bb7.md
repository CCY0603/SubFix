## 用户需求概述

将 SubFix（达芬奇/Fusion 字幕插件）中所有的"勾选框"式选择指示统一改造为按钮样式：

- 选项按钮（如"标准/短视频""Qwen/豆包""热词库""文稿匹配"）不再显示 ☑/☐ 文字前缀；
- 未选中按钮用深灰底+灰边框+灰白字展示，选中按钮用深底+橙色边框+橙色文字（描边高亮，不填充）；
- 音频轨道树行首的 ☑/☐ 改为橙色圆点 ●/○（选中橙、未选中灰）；
- 主窗口三个真实 CheckBox（启用文稿辅助、规整长度两项、中英空格）一并转为灰/橙按钮；
- 待审/回退列表树的 ☑/☐ 同样改为橙色圆点 ●/○。

## 核心特性

- 全插件统一的选择语言：灰色=未选、橙边框=已选、橙点=树中已选，去除方框勾选符。
- 橙色沿用达芬奇品牌橙 #FF6A00；主操作按钮（生成/保存/开始/取消）与状态语义色（红/绿/琥珀）保持不变。
- 功能行为不变：仅替换视觉与选中态的承载控件/符号，不改动业务逻辑。

## 技术栈

- 运行环境：DaVinci Resolve / Fusion 内置 LuaJIT；UI 基于 Fusion UIManager（Qt 控件）。`ui:Button` 支持 `StyleSheet`、`Text`、`Clicked` 事件，选中态靠 `SetAttrs({StyleSheet=...})` 切换。
- 样式机制：核心文件已有 `SUBFIX_BTN_ACCENT`（实底橙，主操作）、`SUBFIX_BTN_BASE`（深灰，未选中）；需新增描边橙 `SUBFIX_BTN_SELECTED`。SubFix.lua 无既有按钮样式常量，需新增同义全局常量（核心文件同名者为 local，作用域隔离，互不冲突）。
- 部署：扁平布局下 `SubFix.lua`→`...Utility\SubFix\SubFix.lua`，`.subfix_support\subfix_generate_selection_core.lua`→`...Utility\.subfix_support\...`；重启 Resolve 使脚本缓存刷新。

## 实现要点

- 无业务逻辑变更：仅替换 UI 声明/符号/选中态承载方式，并引入等价状态变量确保与原有 `.Checked` 读写语义一致。
- 风险点：Button 无 `.Checked` 属性，`get_checkbox_checked` 会返回 false，故所有 CheckBox 调用点必须改为读模块级变量（已在方案内覆盖全部 10 个调用点）。
- 性能：仅样式切换与字符串赋值，无额外开销；`SetAttrs`/`Text` 赋值均用 `pcall` 包裹，沿用既有容错模式。
- 部署前先备份两份目标文件，便于回退。

## 关键代码结构（新增样式常量）

```
-- 选中态：描边高亮（不填充），与用户确认的"橙色边框"一致
local SUBFIX_BTN_SELECTED = "QPushButton{font-size:14px;background-color:#1A212B;color:#FF6A00;font-weight:bold;border:1px solid #FF6A00;border-radius:5px;padding:6px 12px;} QPushButton:hover{background-color:#243240;border:1px solid #FF8C33;}"
-- 树行首与待审树圆点
local TRACK_CHECKED_MARK = "●"      -- 选中（橙）
local TRACK_UNCHECKED_MARK = "○"    -- 未选中（灰）
```

本任务为既有桌面插件（DaVinci Resolve / Fusion UIManager，Qt 控件，非 Web）的视觉翻新：统一"选择"语言的呈现。实际技术栈是 Lua + Fusion UIManager(Qt)，此处 framework 仅作分类占位。

设计目标：去除方框勾选符（☑/☐），以"按钮描边"与"圆点"表达选中，形成一致的达芬奇橙视觉体系：

- 选项按钮：未选中=深灰底(#243240)+灰边框(#34506b)+灰白字(#D6DDE7)；选中=深底(#1A212B)+橙色边框(#FF6A00)+橙字(#FF6A00)，hover 时边框提亮(#FF8C33)。
- 树行首/待审列表：选中显示橙色实心圆点 ●，未选中显示灰色空心圆 ○，与按钮选中色同源。
- 主操作按钮（生成/保存/开始/取消）与状态语义色（错误红 #FF4D4F、成功绿 #00AA55、刷新琥珀 #FA8C16）保持原样，避免状态混淆。
- 整体深色专业主题（背景 #0F141A/#1A212B、文字 #D6DDE7）不变，仅收敛强调色到单一达芬奇橙。
