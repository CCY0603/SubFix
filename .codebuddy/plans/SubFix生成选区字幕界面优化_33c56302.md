## 用户需求

对「SubFix · 生成选区字幕」插件界面做视觉翻新，覆盖**主对话框 + 该插件全部子对话框**（热词库、文稿匹配、清空确认、进度等），保持控件 ID 与业务逻辑不变。

## 核心诉求

- **字体清晰**：统一使用 14px 字体，解决当前字体小、发虚、不清晰的问题。
- **布局优化**：控件之间增加垂直间距（padding/pady），不要挤在一起；音频轨道树当前空白过多，要收敛。
- **底部按钮**：让「生成」与「取消」并排（当前已并排），且「生成」按钮使用醒目颜色。
- **对齐与留白**：修复中间大片空白、组件起始 x 对齐不齐的问题。
- **选中态强调**：对选中的按钮（字幕长度、识别模型、热词/文稿开关）以及勾选的音频轨行，做明显的视觉强调。

## 视觉约束（已与用户确认）

- 强调色：蓝色 `#2D8CF0`。
- 字体：适中 14px。
- 范围：主对话框 + 全部子对话框统一视觉。

## 技术栈

- 运行环境：DaVinci Resolve / Fusion 脚本（Lua 5.1），UI 由 Fusion `UIManager`（基于 Qt5）构建。
- 目标文件：`f:\SubFix-main\SubFix-main\.subfix_support\subfix_generate_selection_core.lua`（由 `生成选区字幕.lua` 通过 `loadfile` 加载，经 `install_subfix.ps1` 整体拷贝到 `...\Fusion\Scripts\Utility\SubFix\` 部署）。
- 无第三方组件库，采用 Fusion 原生控件 + Qt 样式表/通用属性。

## 实现方案

### 1. 共享视觉常量（文件内新增，复用已有模式）

- `DIALOG_FONT = ui:Font{PixelSize = 14}`（同一 `ui:Font` 对象复用于所有控件，参考 `SubFix.lua:19651` 的验证写法）。
- 主色 `ACCENT = {R=45, G=140, B=240, A=255}`（#2D8CF0）；勾选绿 `CHECKED_GREEN = {R=34, G=197, B=94, A=255}`。
- `DIALOG_STYLESHEET`（可选，以 `#ID{...}` 选择器给「生成」按钮蓝色背景/白字/圆角/加粗，以及选中按钮高亮）。

### 2. 主对话框布局改造（约 2287–2358 行）

- 根 `VGroup`：`Spacing` 8 → 约 11；`ContentsMargins` `{12,12,12,18}` → `{16,16,16,18}`；在逻辑分组之间加 `ui:VGap` 增加呼吸感。
- 标签统一：`MinimumSize = {72, 0}` + `Alignment = {AlignRight = true, AlignVCenter = true}`，使「音频轨道/字幕长度/识别模型/热词库/文稿匹配」全部右对齐、其后按钮起始 x 一致 → 解决对齐不齐。
- 音频轨树：由 `Weight = 1` 改为 `Weight = 0`，按实际勾选轨道数给固定高度（如 2 轨≈64px，留少量边距），不再吞噬剩余空间 → 解决中间大片空白与轨道树空白过多；同时按内容收敛窗口 `Geometry` 高度。
- 底部按钮：保留并排 HGroup，「生成」`SetAttrs({BackgroundColor = ACCENT})` + 白字（pcall 容错）；未选中按钮清回默认。

### 3. 选中态视觉强调（改刷新函数，保留 ☑/☐ 文本前缀作为回退）

- `refresh_subtitle_length_buttons()` / `refresh_subtitle_engine_buttons()`：选中按钮加蓝色高亮（BackgroundColor 或 StyleSheet），未选中清回默认。
- `refresh_hotword_ui()` / `refresh_script_match_ui()`：开关“已启用”时蓝色高亮。
- `generate_selection_audio_track_tree_refresh()`（约 1598 行）：对勾选行 `item.TextColor[0] = CHECKED_GREEN` 着色。

### 4. 子对话框一致性

- 用代码探索子代理枚举本文件内其余 `AddWindow`（热词库管理、文稿匹配编辑、清空确认、进度等），逐一应用同一 `DIALOG_FONT` 与等价的间距/边距/选中色规则。
- **严禁改动任何控件 ID 与事件处理函数**，仅改视觉层（字体/间距/颜色/对齐/树高）。

## 实现注意

- 颜色属性（`BackgroundColor`/`StyleSheet`）一律 `pcall` 包裹；若宿主版本不渲染则回退为「文本前缀标记 + 加粗」仍可见选中态，避免白屏。
- 仅做视觉改造，不改变字幕生成、网络请求、校验逻辑。
- 验证：用 Resolve 自带 `lua5.1.dll` 对改后文件做全文件 `luaL_loadfile` 语法校验；重新部署后提醒用户**完全重启达芬奇**生效。

## 设计风格

采用「深色专业工具」风格，呼应 SubFix 主程序已有的暗色基调（背景 #0F141A / #1A212B、浅色文字 #D6DDE7），以蓝色 #2D8CF0 作为唯一点缀强调色，整体克制、清晰、对齐工整。

## 布局方案（按从上到下区块）

1. **标题区**：窗口标题「SubFix · 生成选区字幕」（系统标题栏，无需自绘）。
2. **音频轨道选择区**：一棵紧凑的勾选树（不再拉伸到撑满），行高适中、勾选行用绿色文字强调；上下留白收敛。
3. **参数区（4 行对齐网格）**：每行「右对齐标签（固定宽度 72px）+ 同一起始 x 的按钮组」：

- 字幕长度：标准（≤25字）｜短视频（≤10字）
- 识别模型：Qwen（本地）｜豆包（云端）
- 热词库：开关按钮｜管理…
- 文稿匹配：开关按钮｜文稿…
- 行间垂直间距加大（约 11px），不再拥挤。

4. **状态/范围区**：文稿匹配状态说明、当前选区范围（帧区间 + 片段名），弱化的辅助文字色。
5. **底部操作区**：「生成」（蓝色填充、白字、加粗，权重更大）与「取消」并排同一行，上方留 `VGap` 分隔。

## 交互与强调

- 选中按钮：蓝色背景高亮（pcall 容错，失败则保留 ☑ 前缀 + 加粗）。
- 勾选音轨行：绿色文字。
- 所有控件统一 14px 字体，中文用「微软雅黑/苹方」优先，解决发虚不清晰。
- 窗口尺寸按内容收敛，消除中间大片空白；控件四周内边距统一，视觉更透气。

## Agent Extensions

### SubAgent

- **code-explorer**
- Purpose: 在 `.subfix_support/subfix_generate_selection_core.lua` 中精确枚举所有 `AddWindow` 子对话框（热词库管理、文稿匹配编辑、清空确认、进度等）及其控件 ID 与布局结构，避免遗漏需要统一样式的窗口。
- Expected outcome: 输出一份子对话框清单（窗口 ID、几何尺寸、使用的控件类型与 ID），供主对话框样式规则一致地套用到全部子对话框。
