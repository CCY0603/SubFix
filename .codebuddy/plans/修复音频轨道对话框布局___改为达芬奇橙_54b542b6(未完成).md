## 产品概述

修复 SubFix（达芬奇 / Fusion 字幕插件）当前存在的两个问题：

1. "音频轨道选择"对话框近期回归——窗口高度不足，导致音频轨道列表与"生成/取消"按钮被裁掉，必须手动拉伸窗口才显示。
2. 按用户要求，将插件强调色（蓝 `#2D8CF0`）、勾选标记色（绿 `#22C55E`）及派生高亮统一改为达芬奇品牌橙 `#FF6A00`。

## 核心特性

- 调高"音频轨道选择"对话框的窗口高度，使默认尺寸即完整显示轨道树与生成/取消按钮，无需拉伸。
- 将核心样式中的强调蓝、勾选绿及各类高亮（按钮强调态、Tree 选中、ComboBox 选中、hover 描边）改为 `#FF6A00`。
- 保留错误红、成功绿、刷新中琥珀等状态语义色，避免失去状态区分。
- 重新部署核心文件并重启达芬奇，使改动生效。

## 技术栈

- 运行环境：DaVinci Resolve / Fusion 内置 LuaJIT（宿主注入 `fu`/`fusion`/`bmd`/`resolve` 等全局；UI 基于 Qt 的 Fusion UIManager / QPushButton / QTreeWidget 等控件）。
- 静态分析：Lua Language Server（sumneko），配置于工作区根 `.luarc.json`（已存在，运行时不变量）。
- 部署：复制核心文件到 `%APPDATA%\Blackmagic Design\DaVinci Resolve\Support\Fusion\Scripts\Utility\.subfix_support\`。

## 实现方案

### 对话框布局回归修复（核心文件）

- 目标文件：`f:\SubFix-main\SubFix-main\.subfix_support\subfix_generate_selection_core.lua`，函数 `show_audio_track_selection_dialog`（约第 2259 行），窗口定义在第 2316–2392 行，几何在第 2319 行。
- `centered_geometry({x, y, w, h})`（第 237–252 行）：第 3 位 = 宽、第 4 位 = 高。当前调用 `{460, 250, 440, 310}`，宽 440、高仅 310。
- 内容构成（第 2326–2389 行）：标题 Label + 音频轨道 Tree（`GenerateAudioTrackTree`，`MinimumSize {0,80}`/`MaximumSize {0,200}`） + 4 个选项行（字幕长度 / 识别模型 / 热词库 / 文稿匹配） + 状态 Label + 范围 Label + 生成/取消按钮 HGroup + VGap + 间距/边距，估算内容高度 450px+，远超 310，因此底部轨道树与按钮被裁、拉伸才重排——与用户现象完全吻合。
- 修复：将第 2319 行几何的第 4 个值由 310 提高到可容纳全部内容的值（初算约 470）；为避免轨道项数多时 Tree 撑爆窗口，将第 2331 行的 Tree `MaximumSize` 由 `{0,200}` 收到 `{0,160}`。验收标准：默认尺寸下无需拉伸即可看到轨道树与生成/取消按钮（实施时按实际显示微调高度）。

### 配色改橙（同一核心文件，集中一处）

第 130–153 行集中定义全部强调/勾选/链接色，主窗口 `SubFix.lua` 复用这些全局样式，改核心即级联到所有窗口：

- 第 130 行注释更新为"强调橙 `#FF6A00`、勾选橙 `#FF6A00`"。
- 第 136 行 `SUBFIX_ACCENT_COLOR`：`{R=45,G=140,B=240}` → `{R=255,G=106,B=0}`（#FF6A00）。
- 第 137 行 `SUBFIX_CHECKED_COLOR`：`{R=34,G=197,B=94}` → `{R=255,G=106,B=0}`（#FF6A00，按用户要求绿色勾选也改橙）。
- 第 143 行样式表 hover 边框 `#2D8CF0` → `#FF6A00`。
- 第 146 行 Tree 选中背景 `#2D8CF0` → `#FF6A00`。
- 第 149 行 ComboBox 选中背景 `#2D8CF0` → `#FF6A00`。
- 第 152 行 `SUBFIX_BTN_ACCENT`：其中 `#2D8CF0`（背景/边框，共 3 处）改 `#FF6A00`；hover 的 `#1f7fd6` 改更深的橙 `#CC5600`。
- 第 153 行 `SUBFIX_BTN_BASE` 中性灰 `#243240`/`#34506b` 保持不变。

### 需要保留的语义色（不改）

`SubFix.lua` 中的 `#FF4D4F`（错误/警告红）、`#00AA55`（成功绿）、`#FA8C16`（刷新中琥珀）属状态语义色，非强调/勾选/链接，保持原样以免失去状态区分。

## 实现细节

- 颜色改动集中在核心文件第 130–153 行，全部为常量定义与样式表字符串，改动范围小、无逻辑副作用；主窗口通过全局 `SUBFIX_ROOT_STYLESHEET`/`SUBFIX_BTN_ACCENT` 复用，天然级联到主/小窗口。
- 布局改动仅调整几何高度与 Tree 的 `MaximumSize`，不改变任何业务逻辑、控件 ID 或事件处理。
- 部署：核心文件改动后复制到 `%APPDATA%\Blackmagic Design\DaVinci Resolve\Support\Fusion\Scripts\Utility\.subfix_support\subfix_generate_selection_core.lua`（先备份当前部署版，命名如 `.bak_YYYYMMDD_HHMMSS`）。达芬奇会缓存 Lua 脚本，必须重启 Resolve 才生效。
- 验证：① 打开音频轨道选择对话框，默认尺寸即显示轨道树 + 生成/取消；② 强调按钮、Tree 选中、ComboBox 选中、勾选标记为 `#FF6A00`，主/小窗口同步；③ 重启 Lua 语言服务器 / 重看「问题」面板，确认仍 0 告警（本次改动不引入新诊断）。
